# Recipe-Page

Recipe Page – Frontend mentor challenge

Overview

This project is a frontend mentor challenge built using HTML and CSS. The goal of the project was to practice structuring content with semantic HTML and styling it with modern CSS techniques by creating a clean and visually appealing recipe page.


Features

Semantic HTML structure for better accessibility and readability

Clean and simple layout

Responsive design for different screen sizes

Well-organized recipe sections:

Recipe image

Description

Ingredients list

Preparation steps

Nutrition information


Technologies Used

HTML5

CSS3


What I Learned

While working on this project, I learned:

How to structure a webpage using semantic HTML elements

How to style layouts using CSS

How to manage spacing, typography, and colors effectively

How to convert a design concept into a functional webpage


Challenges Faced

Aligning and spacing different sections consistently

Making the layout visually clean and readable

Ensuring responsiveness across devices


Future Improvements

Add JavaScript for interactivity

Implement dark mode

Improve animations and transitions

Enhance mobile responsiveness
